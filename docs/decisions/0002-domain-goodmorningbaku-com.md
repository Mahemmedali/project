# ADR-0002 — Prod domen: goodmorningbaku.com

**Status:** qəbul edilib · 2026-09-13

Arxitektura sənədi və brend kitabı `goodmorningbaku.az` göstərsə də, layihə sahibi prod üçün **goodmorningbaku.com** domenini təsdiqləyib. `NEXT_PUBLIC_SITE_URL` bu domenə qurulur; kanonik və hreflang URL-lər ondan törəyir. Brend materiallarında (media kit, imza) `.com` istifadə olunmalıdır.
